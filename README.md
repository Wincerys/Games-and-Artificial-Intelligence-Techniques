# Instructions

## Overview
This project implements a deep reinforcement learning agent for Space Invaders using Unity ML-Agents. The agent has been fully trained and can demonstrate learned behaviors including movement, shooting, and parrying mechanics.

## Quick Validation (For Markers)

### Prerequisites
- Unity 2021.3 LTS or later
- **No Python/ML-Agents installation required** (pre-trained models included)

### Testing the Trained AI (Recommended)
1. **Open Unity project**
2. **Open the main game scene**
3. **Find the ML-Agent GameObject** with SpaceInvadersAgent script
4. **In Behavior Parameters component**:
   - Set Behavior Type to **"Inference Only"**
   - Drag the pre-trained `.onnx` file to **Model** field
   - Set Vector Observation Space Size to **776**
   - Set Vector Action Space Type to **Discrete**
   - Set Branches Size to **3**
   - Branch sizes: **3, 2, 2** (movement, shooting, parrying)

5. **Press Play** - AI controls the player automatically

### Expected AI Performance
- ✅ **Strategic Movement**: Dodges enemy projectiles intelligently
- ✅ **Accurate Shooting**: Targets invaders efficiently  
- ✅ **Parry Mechanic**: Ship flashes cyan when parrying missiles
- ✅ **High Scores**: Consistently achieves 2000-20000+ points
- ✅ **Long Survival**: Episodes last 1000+ steps
- ✅ **Multi-Wave Completion**: Clears multiple invader waves

### Success Criteria
The AI demonstrates successful learning if it:
- Performs better than random play
- Uses all three mechanics (move, shoot, parry)
- Achieves consistent scores above 500
- Survives significantly longer than untrained agent

## Complete Project Setup (Reference)

### Layer Configuration
Go to `Edit → Project Settings → Tags and Layers` and add:
- Layer 6: `Player`
- Layer 7: `Invader` 
- Layer 8: `Laser`
- Layer 9: `Missile`
- Layer 10: `Bunker`
- Layer 11: `Boundary`

### Physics Setup
- `Edit → Project Settings → Physics 2D`
- In "Layer Collision Matrix", uncheck "Missile" × "Invader" intersection

### Game Manager Setup
Create GameObject "GameManager" with `GameManager.cs`:
- Assign 3 player ship prefabs
- Set player spawn point
- Link UI elements (score, lives, game over screens)

### Player Ship Types

**Ship 1 - Balanced:**
- Speed: 5, Cooldown: 0.5s, Damage: 4
- Single laser shots
- Invincibility: 2.5s with blinking

**Ship 2 - Fast (Used for AI training):**
- Speed: 10, Cooldown: 0.3s, Damage: 2  
- Arc shots (multiple projectiles)
- Invincibility: 2.5s with blinking

**Ship 3 - Heavy:**
- Speed: 3, Cooldown: 2s, Damage: 8
- Rocket launcher with magazine system
- Invincibility: 2.5s with blinking

### Invader System
Create "Invaders" GameObject with `Invaders.cs`:

**Formation Settings:**
- Rows: 6, Columns: 21
- Multiple formation types (Fortress, Wings, Diamond, etc.)
- Guaranteed boss and special invader spawning

**Invader Types:**
- **Normal (1×1)**: Basic invaders, participate in group attacks
- **Strong (2×2)**: Independent burst fire attacks  
- **Boss (3×3)**: Multi-directional spread attacks

### Projectile Types
- **Player Laser**: Standard projectile
- **Arc Shot**: Fast multi-directional shots
- **Rocket**: Heavy damage with explosion radius
- **Invader Missiles**: Various enemy projectile types

### Bunker System
- Destructible terrain with `Bunker.cs`
- Pixel-perfect collision detection
- Gradual destruction from impacts

### Parry System
**Visual Effects:**
- Ship changes to cyan color during parry window
- Color pulses for visibility
- Console logs for successful parries

**Mechanics:**
- 5-frame parry window
- 10-second cooldown
- Destroys incoming missiles
- AI receives reward for successful parries

### Advanced Features

**Formation System:**
- 8+ different strategic formations
- Boss placement in formation-appropriate locations
- Density control (0.3-1.0 fill percentage)
- Static or moving formation options

**AI Training Features:**
- 776-dimensional observation space
- 3 discrete action spaces (movement, shooting, parrying)
- Environment randomization support
- Automatic episode restart system

### Troubleshooting
- **AI doesn't move**: Check Behavior Type is "Inference Only"
- **No parry effects**: Verify 3 action branches configured
- **Low performance**: Ensure correct .onnx model loaded
- **Physics issues**: Verify layer collision matrix setup

### Technical Details
- **Algorithm**: PPO (Proximal Policy Optimization)
- **Training Duration**: ~8-12 hours on standard hardware
- **Model Size**: ~8MB final .onnx file
- **Observation Space**: Environment grid + player state + parry info
- **Action Space**: Discrete (move left/stay/right, shoot yes/no, parry yes/no)
